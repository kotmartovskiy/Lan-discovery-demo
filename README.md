# LAN Discovery — демо-панель

Статичный **слепок** веб-панели LAN Discovery: устройства, мониторинг,
погода, инвентаризация, системы — снимок данных на дату, указанную в плашке
внизу экрана.

- Данные **не обновляются** при просмотре — это HTML-снимок.
- Внешние ссылки и кнопки действий перенаправляются на страницу-заглушку
  с кнопкой «Назад».
- Раздел «⚠ Restore» ведёт на слепок Emergency Restore Server (кнопки в нём
  отключены).
- Заметки и пароли вычищены из демо.

Обновление слепка (генератор в основном репозитории):

```bash
# на хосте панели
cd /opt/lan-discovery && venv/bin/python tools/make_demo.py /tmp/demo
# скачать, проверить, запушить сюда
python tools/demo_lint.py <папка-demo>
```
